# AgentVoice

[![CI](https://github.com/mxn2020/agentvoice/actions/workflows/ci.yml/badge.svg)](https://github.com/mxn2020/agentvoice/actions/workflows/ci.yml)
[![License: Apache-2.0](https://img.shields.io/badge/License-Apache--2.0-yellow.svg)](https://opensource.org/licenses/Apache-2.0)

AI-powered voice agent platform for automated phone calls and communication

## Tech Stack
- **Frontend**: Vite + React + TypeScript
- **Styling**: Vanilla CSS (dark theme design system)
- **UI Library**: @geenius-ui/react-css
- **Backend**: Convex (Serverless)
- **Auth**: Convex Auth (email/password)
- **Payments**: Stripe (subscriptions)
- **AI**: NVIDIA NIMs
- **Analytics**: Vercel Analytics

## Quick Start

```bash
cd web
pnpm install
npx convex dev        # Start Convex backend
pnpm run dev          # Start Vite dev server
```
